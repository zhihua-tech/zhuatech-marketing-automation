# 营销自动化平台企业能力

## 领域覆盖

- **客户分群**：基于标签、行为和价值构建动态人群
- **营销活动**：管理目标、预算、渠道、排期和负责人
- **营销内容**：管理模板、素材、版本和审批
- **自动旅程**：通过触发器、条件和动作编排培育流程
- **线索评分**：按画像、意向和互动计算线索分值
- **营销同意**：管理订阅偏好、退订和触达合规
- **触达执行**：连接邮件、短信、企微和广告渠道
- **转化归因**：分析触点、商机、订单和收入贡献
- **营销分析**：跟踪漏斗、ROI、获客成本和留存

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对营销自动化平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `CRM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
